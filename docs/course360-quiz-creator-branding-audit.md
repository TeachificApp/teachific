# Course360 Quiz Creator Branding Audit

## Purpose

This audit records the visible Quiz Creator platform labels normalized to **Course360™** and the legacy values intentionally retained for compatibility. It applies only to platform-owned copy. Organization-owned names, logos, colors, and learner domains continue to take precedence wherever the active organization supplies them.

## Normalized visible surfaces

| Surface | Approved visible label |
|---|---|
| Quiz Creator landing, upgrade, and workspace pages | Course360 Quiz Creator™ |
| Public standalone quiz attribution | Course360 Quiz Creator |
| Question Bank sharing controls | Course360 Quiz Creator |
| Quiz import guidance | Course360 |
| Desktop app download catalog | Course360 Creator™, Course360 Studio™, and Course360 Quiz Creator™ |
| Root-platform sign-in copy | Course360™ and Course360 app names |
| Platform-domain examples and help link | `course360.app` |

## Compatibility exclusions

The following values are **not user-facing platform labels** and remain unchanged to preserve existing records, browser data, file compatibility, integrations, and working contact routes.

| Value category | Examples | Reason retained |
|---|---|---|
| Serialized Quiz Creator fields | `teachificOrgId`, `teachificEmail` | Existing persisted quiz and integration contracts |
| Browser storage keys | `teachific_quiz_license`, `teachific_quiz_recent` | Existing users' locally stored Quiz Creator state |
| Portable file format markers | `TEACHIFIC_QUIZ_V1`, legacy salt | Backward compatibility for existing `.quiz` imports and exports |
| Legacy routing checks | `teachific.app` subdomain detection | Supports the deployed legacy domain during the Course360 transition |

## Content integrity

Fabricated testimonials, ratings, named endorsements, and unsupported performance statistics were removed from the Quiz Creator and Creator landing pages. Their prior social-proof sections now describe factual product workflows instead.
